
# 🌱 SIX_Q - Mini Greenhouse


## Elevator Pitch

A small, automated growing system built around an Arduino UNO Q board and designed for others to reproduce. The goal is to present a simple, working prototype that others can use as a starting point to build, modify, and experiment with their own. It was built using very inexpensive, readily available materials, so you have no excuses! Take the best ideas, build with what you have on hand, and improve it, wherever you are.

## System Structure

The system consists of three levels:

### 1. Base

The frame can expand both horizontally and vertically. Once extended, it is secured using the side bars.
The bag containing the growing medium is then inserted and secured. This prototype uses approximately 1.8 kg
of commercial potting soil.



### 2. Middle Level

This level houses the lighting and irrigation systems. For safety, the submersible water pump and reservoir are placed to one side,
outside the frame.



### 3. Electronics

The electronics are located at the top of the frame.

These include:

- a push button to activate irrigation locally;
- a push button to control the lighting;
- Arduino UNO Q;
- sensors and associated modules;
- a vision system using Nicla Vision.
